ARUT-HARDT Engine mannequin asset license and provenance
=========================================================

Asset: Animated Robot by Quaternius
Official asset page: https://quaternius.itch.io/lowpoly-robot
Alternative catalogue record: https://poly.pizza/m/QCm7qe9uNJ
License: Creative Commons CC0 1.0 Universal
License text: https://creativecommons.org/publicdomain/zero/1.0/

The original asset page explicitly identifies the pack as CC0 and lists 14
animations. CC0 permits redistribution and modification. This repository keeps
the source and license information for provenance even though CC0 does not
require attribution.

Included file:
  arut_test_mannequin.gltf

Modifications by ARUT-HARDT Engine:
- Changed embedded PBR material colors to a matte white/light-gray robotic shell,
  light titanium joints, and a dark graphite faceplate.
- Kept the authored model mesh data, armature/skeleton hierarchy, mesh skin
  weights, source rest transforms, and original animation channels.
- Packed the GLB binary buffer into a glTF data URI so the character is a single
  self-contained text resource with no companion .bin or texture download.

Rig/clip audit from the source glTF:
- Two skin records, with a 43-joint humanoid robot armature.
- Finger bones include thumb, index, middle and ring chains for both hands.
- 14 named clips: Dance, Death, Idle, Jump, No, Punch, Running, Sitting,
  Standing, ThumbsUp, Walking, WalkJump, Wave and Yes.
- The shell is authored as hard-surface mesh sections attached to named rig
  joints; the articulated hand meshes have JOINTS_0 / WEIGHTS_0 skin attributes.
  This is a rigged robot model, not a single continuous soft-body human surface
  and not an engine-generated primitive assembly.

The code and any ARUT-authored integration remain under the ARUT repository's
MIT license. This notice does not change the separate CC0 license of the model
and animation data.
